# ClassTalk 계정 연결형 전사 워커

이 디렉터리는 일반 교사가 설치하는 앱입니다. 운영자용 `app.worker`와 달리
`.env`, Supabase 비밀 키, 교사 비밀번호를 사용하지 않습니다.

## 교사 사용 방법

전사 워커는 **녹음 파일을 글로 바꿀 교사 컴퓨터에 설치하는 프로그램**입니다.
녹음하는 휴대전화에는 설치하지 않습니다. Python과 음성 처리 도구가 포함되어 있어
Python·FFmpeg를 따로 설치하거나 API 키를 입력할 필요가 없습니다.
설치하는 선생님이 개발자 계정에 가입하거나 서명 인증서를 구매할 필요도 없습니다.

### 1. 내 컴퓨터에 맞는 파일 받기

[ClassTalk 전사 워커 페이지](https://classtalk-web-three.vercel.app/worker#downloads)에서
설치 파일을 받습니다. 이 페이지는 로그인 전에도 열 수 있습니다.
페이지의 다운로드 버튼은 공식 배포 저장소인
`github.com/phdkim0244-droid/classtalk-worker-downloads`로 연결됩니다.

| 컴퓨터 | 선택할 파일 | 내 컴퓨터 확인 방법 |
| --- | --- | --- |
| Windows 10 이상, Intel·AMD 64비트 PC | Windows x64 · `…windows-x64-Setup.exe` | **설정 → 시스템 → 정보 → 시스템 종류**에서 x64 기반 프로세서인지 확인 |
| Apple M1·M2·M3 등 M 시리즈 Mac | Mac Apple Silicon · `…macos-arm64.dmg` | **Apple 메뉴 → 이 Mac에 관하여**에 Apple M 시리즈 칩 표시 |
| Intel Mac | Mac Intel · `…macos-x64.dmg` | **Apple 메뉴 → 이 Mac에 관하여**에 Intel 프로세서 표시 |

Mac은 macOS 13 이상이 필요합니다. Mac 실행 검증은 macOS 15의 Apple Silicon·Intel
환경에서 수행했으며, macOS 13·14는 별도 실행 검증 전입니다. Windows 32비트 또는
Windows ARM 컴퓨터는 현재 제공하는 설치 파일의 검증 대상이 아닙니다.

### 2. 설치하고 프로그램 열기

**Windows**

1. 내려받은 `ClassTalk-Worker-…-windows-x64-Setup.exe`를 실행합니다.
2. 설치 화면의 안내에 따라 **Next(다음)**로 진행합니다. 포함된 라이선스 안내를 확인하고 동의하면
   **I accept the agreement**를 선택합니다. **Install(설치)**로 설치하고 **Finish(마침)**를 누릅니다.
3. 설치가 끝나면 시작 메뉴에서 **ClassTalk Worker**를 엽니다.

**Mac**

1. 내려받은 `.dmg` 파일을 두 번 클릭합니다.
2. 열린 창의 **ClassTalk Worker** 앱을 **Applications(응용 프로그램)** 폴더로 끌어 놓습니다.
3. 복사가 끝나면 Finder의 **응용 프로그램**에서 **ClassTalk Worker**를 엽니다.
   DMG 창 안의 앱을 계속 사용하는 대신 복사한 앱을 실행하세요.

### 3. 처음 실행할 때 경고가 나오는 경우

현재 초기 배포본은 정식 코드 서명·Mac 공증 전입니다. 컴퓨터에 따라 제작자를 확인할 수
없다는 안내가 나올 수 있으며, 모든 컴퓨터에서 설치가 허용되는 것은 아닙니다.
**위 공식 다운로드 페이지에서 받은 파일이며 출처를 신뢰하는 경우에만** 아래 절차를 확인하세요.

- **Windows의 알 수 없는 앱에 대한 SmartScreen 경고:** **추가 정보**를 눌렀을 때
  **실행** 버튼이 제공되는 경우에만 앱 이름과 내려받은 파일을 확인한 뒤 선택할 수 있습니다.
  실행 버튼이 없거나 Smart App Control·학교 관리 정책으로 차단되면 중단하고 학교 담당자에게 문의하세요.
- **Mac의 확인되지 않은 개발자·공증 확인 불가 안내:** 응용 프로그램에서 앱을 한 번 열어 본 뒤
  **시스템 설정 → 개인정보 보호 및 보안**으로 이동합니다. ClassTalk에 대한
  **그래도 열기** 버튼이 제공되는 경우에만 선택하고, 다시 나타나는 창에서 **열기**를 확인합니다.
  버튼이 없거나 관리 정책으로 제한되면 학교 담당자에게 문의하세요.
- **악성코드 감지, ‘컴퓨터를 손상시킵니다’, ‘앱이 손상되었습니다’ 등의 경고**는 위 안내와 다릅니다.
  실행하지 말고 경고 문구와 받은 파일 이름을 ClassTalk 운영자에게 알려 주세요.

백신, Smart App Control, Mac 보안 기능을 끄거나 학교 정책을 우회하지 마세요.
참고: [Apple의 앱 실행 안내](https://support.apple.com/ko-kr/102445),
[Microsoft의 SmartScreen 안내](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

### 4. 본인 교사 계정 연결하기

1. 앱에서 **계정 연결 / 시작**을 누릅니다. 브라우저가 열리면 본인 ClassTalk 교사 계정으로 로그인합니다.
   계정이 없다면 웹에서 먼저 가입합니다. 앱에 교사 비밀번호를 입력하는 절차는 없습니다.
2. 앱과 웹의 **연결 코드**가 같은지, 웹의 **기기 이름**이 내 컴퓨터인지 확인합니다.
3. 웹에서 **내 컴퓨터의 프로그램에 표시된 코드와 기기 이름이 일치합니다.**에 체크한 뒤
   **본인 수업 전사 허용**을 누릅니다. 코드는 발급 후 10분 안에 승인해야 합니다.
4. 앱에 **본인 계정 연결됨**이 표시되면 연결된 것입니다. 이어서 모델 준비가 시작됩니다.

브라우저가 자동으로 열리지 않으면 앱의 **계정 연결 화면 열기**를 누릅니다.
그래도 열리지 않으면 [연결 코드 입력 화면](https://classtalk-web-three.vercel.app/worker/connect)에
직접 접속하여 로그인한 뒤, 앱의 코드를 입력하고 **연결 요청 확인**을 누릅니다.
만료된 코드는 앱에서 **중지** 후 **계정 연결 / 시작**을 눌러 새로 받습니다.

기본 **자동** 설정은 macOS 15 이상의 Apple Silicon Mac에서 GPU를 사용합니다. Windows·Intel Mac·이전 macOS는 CPU에서 최대 28초씩 묶어서 처리합니다. **CPU 호환**을 선택하면 이전의 발화별 처리 방식으로 돌아갑니다. GPU 준비에 실패하면 중지된 상태에서 **CPU 호환**을 선택하고 다시 시작할 수 있습니다. 처리 방식은 작업 중 바꿀 수 없습니다.

처음 시작할 때 공개 Whisper large-v3 모델을 약 3.1GB 내려받습니다. GPU용과 CPU용 모델 캐시는 별도이므로 처리 방식을 처음 바꾸면 추가 다운로드가 필요합니다. 인터넷 연결을 유지하고
**대기 중 · 연결한 계정의 전사 요청만 확인합니다.**가 나올 때까지 기다리세요.
준비 시간은 컴퓨터와 네트워크에 따라 다릅니다. 다음부터는 저장된 모델을 사용합니다.
이전 버전의 모델이 있어도 새 모델은 한 번 내려받습니다. 모델 크기만큼 추가 저장 공간이
필요하고 기존 캐시는 자동으로 지우지 않습니다. 큰 모델도 숫자·단위·용어를 오인식할 수
있으므로 중요한 수치와 분석 근거는 원음과 함께 확인하세요.

### 5. 수업 녹음을 전사하고 분석하기

1. 웹의 [교사 대시보드](https://classtalk-web-three.vercel.app/dashboard)에서 수업 세션을 만들거나
   기존 세션을 엽니다. 워커에 연결한 계정과 같은 계정이어야 합니다.
2. 참가 코드로 연결한 녹음 기기에서 수업을 녹음하고 업로드를 마칩니다. 이미 녹음한 파일이 있다면
   수업 화면의 **음성 파일 업로드**에서 채널과 파일을 선택해 **업로드**합니다(파일당 50MB 이하).
   녹음 기기에는 워커를 설치할 필요가 없습니다.
3. 업로드된 녹음이 있는지 확인한 뒤 **음성 전사 → 전사 시작**을 누릅니다.
4. 웹의 상태가 **요청됨 (전사 프로그램 연결 대기) → 전사 중… → 전사 완료**로 바뀝니다.
   앱에는 수업 이름, 현재 파일 번호, 처리 단계와 경과 시간이 표시됩니다.
   **전사 중 N%**는 무음을 제외한 감지된 음성 길이 중 전사를 마친 비율입니다.
   **화자 특징 추출 중 N%**는 처리한 음성 구간 수의 비율입니다. 각 단계·파일마다
   진행률이 새로 시작하며, 전체 수업의 완료 비율을 뜻하지 않습니다.
   최소 3개 구간과 10초의 처리 기록이 쌓이면 **현재 단계 남음 약 M:SS**를 표시합니다.
   전사 단계에는 음성 길이 대비 처리 배속도 표시합니다. 초기에는 **남은 시간 계산 중**,
   구간 처리가 오래 걸려 추정이 낡으면 **추정 갱신 대기**로 표시하며 타이머만으로 완료 처리하지 않습니다.
   남은 시간에는 다음 단계·다음 파일·웹 AI 분석이 포함되지 않으며 구간 난이도에 따라 변합니다.
   음성 파일 받기·읽기·모델 준비·화자 구분·저장처럼 비율을 알 수 없는 단계는 움직이는
   막대로 표시합니다. 긴 구간을 처리하는 동안 숫자가 잠시 그대로여도 경과 시간은 갱신됩니다.
   모든 파일의 서버 저장을 확인한 뒤 **전사 완료**로 바뀝니다.
5. 완료되면 웹에서 전사 내용을 확인합니다. 분석이 필요하면 **AI 분석 (교육과정 연계 · 수업 대화)**에서
   분석 모듈과 LLM 모델을 선택하고 **분석 실행 (N건)**을 누릅니다. 분석은 전사 후 웹에서 별도로 실행합니다.

전사 중에는 **워커 앱, 인터넷 연결, 컴퓨터 전원을 유지**하세요. 노트북 덮개를 닫거나
컴퓨터가 잠자기에 들어가면 처리가 중단될 수 있습니다. 수업이 길거나 컴퓨터가 느리면 오래 걸릴 수 있습니다.
앱은 선택된 로컬 GPU 또는 CPU에서 음성을 처리하며, 연결한 교사 계정이 만든 수업만 처리합니다.
GPU 가속은 large-v3를 유지하며, 메모리 내 8비트 가중치와 최대 30초 묶음으로 반복 계산을 줄입니다. 무음을 삭제해 이어 붙이지 않고 원래 시각을 보존해 화자를 구분합니다.
MLX의 결정적 greedy 디코딩을 사용하므로 CPU beam-5와 전사 문구가 달라질 수 있습니다. 숫자·단위와 주요 분석 근거는 원음으로 확인하세요.
40분 수업을 10분 안에 처리하는 속도는 모든 컴퓨터에서 보장되지 않습니다. 다운로드·모델 준비·웹 분석 시간은 별도입니다.
화자 수는 수업·모둠 설정을 따르고 학생 이름은 학생1, 학생2처럼 표시합니다.

### 6. 다음 수업, 종료, 계정 바꾸기

- **다음 수업:** 앱을 열고 **계정 연결 / 시작**을 누릅니다. 연결이 유지되어 있으면 새 코드 승인 없이
  모델을 준비하고 대기합니다. 이후 웹에서 해당 수업의 **전사 시작**을 누르면 됩니다.
- **오늘 사용 마치기:** 웹의 **전사 완료**를 확인한 뒤 앱의 **중지**를 누르고 종료합니다.
  앱을 닫으면 전사 처리가 멈춥니다. 창을 닫아도 계속 실행되는 프로그램이 아닙니다.
- **공용 컴퓨터·계정 변경:** 앱에서 **중지**하고 중지가 끝나면 **연결 해제**를 누릅니다.
  또는 웹의 [전사 워커 → 연결 상태 확인](https://classtalk-web-three.vercel.app/worker#devices)에서
  해당 기기의 **연결 해제 → 연결 해제 확인**을 누릅니다. 웹 계정 로그아웃만으로는 워커 연결이 해제되지 않습니다.
  다른 선생님은 자신의 웹 계정으로 로그인한 뒤 새 연결 코드를 승인합니다.

### 문제가 생겼을 때

| 보이는 상황 | 확인할 내용 |
| --- | --- |
| **전사 시작**을 누를 수 없음 | 해당 세션에 녹음 업로드가 끝났는지 확인합니다. 전사 요청·진행 중이면 완료될 때까지 버튼이 비활성화됩니다. |
| **요청됨 (전사 프로그램 연결 대기)**에서 멈춤 | 워커의 **계정 연결 / 시작**을 눌렀는지, 모델 준비가 끝났는지, 같은 교사 계정으로 연결했는지 확인합니다. 컴퓨터의 인터넷·전원도 확인합니다. |
| 모델 준비 또는 시작 실패 | 인터넷과 저장 공간을 확인한 뒤 다시 시작합니다. 학교 네트워크에서 모델 다운로드가 차단되면 담당자에게 문의합니다. |
| 연결 코드 만료 | 앱의 **중지** 후 **계정 연결 / 시작**으로 새 코드를 받고 10분 안에 승인합니다. |
| 전사 중 앱을 종료했거나 인터넷이 끊김 | 연결을 복구하고 워커를 다시 시작합니다. 작업 잠금이 만료되면 남은 요청을 다시 처리할 수 있습니다. 웹에 **오류**가 표시되면 안내를 확인하고 **전사 시작**을 다시 누릅니다. |
| 설치나 실행 자체가 차단됨 | 위 경고 종류를 확인합니다. 악성코드·손상 경고 또는 학교 정책 차단은 실행을 시도하지 말고 운영자·학교 담당자에게 문의합니다. |

문의할 때는 운영체제, 설치 파일 이름, 화면의 오류 문구를 알려 주세요.
비밀번호·연결 코드·학생의 실제 음성이나 전사 내용은 함께 보내지 마세요.

## 개발 및 패키징

Python 3.11의 가상 환경을 사용합니다. 설치 사용자에게 이 단계는 필요하지 않습니다.

```sh
cd pipeline
python -m pip install -r requirements-desktop.txt
python -m unittest discover -s desktop/tests -v
python -m desktop.main
# 계정 연결·실제 작업 없이 새 화면 확인
python -m desktop.main --preview-ui
# 명시한 loopback 주소만 허용. 다른 원격 서버로 토큰을 전송할 수 없습니다.
python -m desktop.main --dev-server http://localhost:3000
```

OS별 빌드:

```sh
# macOS, 실행 컴퓨터의 아키텍처로 빌드
bash packaging/build-macos.sh
# Windows PowerShell, Inno Setup 6 필요
./packaging/build-windows.ps1
```

GitHub Actions `Build ClassTalk desktop worker`는 Windows x64, macOS arm64,
macOS x64에서 각각 빌드하며 **완성된 실행 파일**의 `--self-test`를 실행합니다.
Windows에서는 실제 Setup.exe 설치 후 설치된 앱도 검사합니다. self-test는 네트워크나
계정을 사용하지 않고 Tk, 음성 디코더, VAD 모델, 화자 모델, 클러스터링의 동작을 검사합니다.
결과는 `dist/self-test.json`, 설치 파일·SHA256은 `dist/installers/`에 생성됩니다.
별도의 `--model-smoke-audio` 검사는 공개 모델을 다운로드한 뒤 12초짜리 한국어 합성
음성을 완성된 앱에서 전사하여 한국어 인식·화자 라벨·타임스탬프를 확인합니다.
같은 실행의 `--model-smoke-regressions desktop/tests/fixtures/model-regressions.json`은
별도 합성 음성에서 8mL·9mL·2mL·1mL의 숫자와 단위를 검사합니다. 기대값은 전사 후
검사에만 쓰며 모델 프롬프트나 교정에 전달하지 않습니다. 두 OS 빌드가 이 검사를 포함합니다.
마이크, 계정 또는 실제 수업 녹음을 사용하지 않으며 결과는 `dist/model-smoke.json`입니다.

Actions 산출물은 자동으로 공개되지 않습니다. 검증된 세 플랫폼의 산출물과 체크섬을
배포 저장소에 올리고 웹의 다운로드 목록을 갱신해야 합니다. 개인 저장소의 Actions
산출물 링크를 일반 사용자용 다운로드 주소로 사용하지 마세요.

Mac 빌드 시 `MACOS_SIGN_IDENTITY`를 설정하면 Developer ID로 서명합니다.
`MACOS_NOTARY_PROFILE`을 설정하면 해당 키체인 프로필로 공증하고 결과를 스테이플합니다.
키와 인증서는 빌드 머신의 보안 저장소에만 둡니다.

## 프로토콜 및 실패 처리

- 모든 API 요청은 고정 운영 origin의 `/api/worker/`로만 갑니다.
- 브라우저 기기 연결로 받은 토큰만 OS 보안 저장소에 저장합니다. 평문 파일 대체 경로는 없습니다.
- 모델을 준비한 후 작업을 청구합니다. 작업당 20초 heartbeat, 서버 잠금 120초입니다.
- 401은 연결 해제로 처리합니다. 409 또는 heartbeat 실패 후에는 결과를 제출하지 않습니다.
- 서버 요청 재시도는 최대 3회입니다. 결과 저장은 녹음 ID+lease를 사용해 중복을 막습니다.
- 오디오 다운로드는 별도 HTTP 클라이언트를 사용합니다. worker 토큰, 쿠키, netrc를 전달하지 않습니다.
- 오디오 URL은 HTTPS Supabase Storage 서명 주소만 허용하고 리다이렉트를 거부합니다.
- 긴 수업도 뒤쪽 녹음의 주소가 만료되지 않도록 각 파일 다운로드 직전에 현재 작업 잠금으로 새 주소를 요청합니다.
- 일시 다운로드 파일은 전사 완료/실패 시 삭제됩니다. 모델 캐시는 남습니다.
- API 키/비밀번호/음성/전사 내용을 로컬 로그에 저장하지 않습니다.
