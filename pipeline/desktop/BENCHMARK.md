# 로컬 워커 가속 검증

## 재현 범위

검증일: 2026-10-18. Apple M5, 메모리 16GB, macOS 26.6.2.
합성 대화 파일은 교사/학생 4개 목소리를 포함하며 길이는 171.6975625초입니다.
SHA256: `c70a7b8cc87d1619de6d3cb102b98fef9b4b8f48cba2ec1a5f4bde0ae1ae585c`.
기대 대본/숫자는 전사 후 평가에만 사용하며 디코더 입력·프롬프트·교정에 사용하지 않았습니다.

| 방식 | 전사+화자 구분 | 정규화 CER | 수량·단위 문항 |
| --- | ---: | ---: | ---: |
| 기존 CPU large-v3, 발화별 beam-5 (이전 기록) | 377.05초 | 9.39% | 6/6 |
| CPU large-v3, 28초 원음 묶음 beam-5 | 324.01초 | 7.54% | 6/6 |
| GPU large-v3, 30초 원음 묶음, 8비트 greedy | 57.56초 | 7.82% | 6/6 |

세 경우의 38개 발화 시각/화자 라벨은 동일합니다. 별도 2mL/1mL 및 8mL/9mL
합성 대비 검사도 통과했습니다. 6개 문항은 수량·단위 10개를 검사합니다.
발화 길이는 기존 VAD 추정이며 정확한 발성 시간 또는 강제 정렬이 아닙니다.
CER는 한글 음절·숫자를 그대로 비교하므로 `이`와 `2` 같은 표기 차이도 오류에 포함됩니다.

이전 CPU 기록과 동시 부하가 통제된 비교가 아닙니다. 시험 중 기존 워커도 실행 중이었으며,
모델 다운로드·준비·서버 전송·웹 AI 분석 시간은 표에서 제외했습니다.
짧은 합성 파일로 실제 40분 교실 음성의 속도 또는 어린이/겹친 발화의 정확도를 보장하지 않습니다.

## 자동 회귀

`python -m unittest discover -s desktop/tests -v`

Mac에서 실제 UI도 검사하려면 `CLASSTALK_UI_TEST=1`을 설정합니다.
완성된 앱의 `--model-smoke-audio`, `--model-smoke-regressions`는 모델 실행과 수량 회귀를
검사합니다. `--model-smoke-cache /absolute/cache`로 이미 내려받은 공개 모델을 재사용할 수 있습니다.
`--acceleration cpu`는 기존 CPU 호환 경로를 검사합니다. 이 검증 경로는 API 클라이언트,
계정 보안 저장소 또는 마이크를 열지 않습니다.

## 진행률과 예상 시간

진행률은 완료된 VAD 음성 길이 또는 화자 임베딩 구간 수로 계산합니다. ETA는 파일/단계별로
초기화하고 최소 3개 완료 구간과 10초가 쌓인 뒤 최근 최대 20개 표본으로 추정합니다.
UI 타이머만으로 진행률이 오르거나 완료되지 않습니다. 다운로드/모델 준비/저장 시간 및
다음 파일은 현재 단계 ETA에 포함하지 않습니다. 전체 수업 ETA라고 표시하지 않습니다.

## 40분 길이 실측 및 완성 앱

동일 합성 대화를 반복해 만든 2,400초 파일(실제 수업 녹음 아님)을 GPU로 처리한 결과,
전사·화자 구분은 **713.46초(11분 53초)**, 모델 준비는 별도 5.32초였습니다.
업로드·결과 전송·웹 AI 분석은 포함하지 않습니다. 따라서 40분 수업의 전사+분석 10분 목표를
달성했다고 판단할 수 없습니다. 시험 중 기존 워커·빌드·검증 작업이 일부 함께 실행됐습니다.
40분 파일 SHA256: `f8c9a0decc2504ef4ec7a45c6ace6bb64c57011bce8526ddd15c045081854140`.

회귀 검사 49개, 최종 Mac arm64 앱의 기본 self-test와 실제 GPU 전사/수량 smoke 모두 통과했습니다.
Mac 앱 ad-hoc 서명 무결성 및 DMG 체크섬 검증을 통과했습니다. Developer ID 서명/공증은 아닙니다.
새 Windows/Intel Mac 설치 파일 실행은 이번 Mac에서 검증하지 않았습니다. 운영 릴리스와 설치된
실행 중 워커는 변경하지 않았습니다.

40분 실측 로그를 실제 ETA 계산기에 다시 입력한 결과, 진행률 20–90% 구간에서
남은 시간의 중앙 상대 오차는 전사 약 4.4%, 화자 특징 추출 약 23.0%였습니다.
빠른 화자 구간이 연속돼 최근 20개 표본이 10초 미만이더라도 단계 전체 관측 시간이
10초를 넘으면 ETA를 표시하도록 회귀 검사를 추가했습니다. 추정은 보장이 아니며
구간 길이·CPU 부하에 따라 오차가 커집니다.
