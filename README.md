# ClassTalk 전사 프로그램

ClassTalk에서 녹음한 **내 수업**을 선생님 컴퓨터에서 전사하는 프로그램입니다. Python이나 FFmpeg를 따로 설치하지 않아도 됩니다.

## 다운로드

[ClassTalk 다운로드 페이지](https://classtalk-web-three.vercel.app/worker)에서 컴퓨터에 맞는 설치파일을 받을 수 있습니다. [최신 공개 릴리스](https://github.com/phdkim0244-droid/classtalk-worker-downloads/releases/latest)에도 설치파일과 체크섬을 제공합니다.

## 지원 환경

- Windows 10 이상, x64
- macOS 13 이상, Apple Silicon 또는 Intel (각각 다른 파일)

Mac 실행 검사는 macOS 15의 Apple Silicon·Intel 환경에서 수행했습니다. macOS 13·14에서는 별도 실행 검증을 하지 않았습니다.

## 사용 순서

1. 본인 컴퓨터에 맞는 설치파일을 받습니다.
2. Windows는 Setup.exe로 설치하고, Mac은 DMG 안의 앱을 Applications로 옮깁니다.
3. 프로그램의 **계정 연결 / 시작**을 누릅니다.
4. 열린 ClassTalk 브라우저에서 본인 교사 계정으로 로그인하고, 기기 이름과 연결 코드를 확인한 후 승인합니다.
5. 0.2.0을 처음 시작하면 공개 Whisper medium 음성 인식 모델 약 1.5GB를 내려받습니다. 모델 준비가 끝날 때까지 인터넷 연결과 앱을 유지합니다.
6. 웹 수업 화면에서 **전사 시작**을 누르고 이 프로그램을 켜 둡니다. 결과는 웹 전사본에서 확인합니다.

본인 계정이 만든 수업만 배정됩니다. 학생 녹음 기기에는 설치할 필요가 없습니다. 전사 후 AI 내용 분석은 기존 ClassTalk 웹 기능을 사용합니다.

## 0.2.0으로 업데이트

기존 전사 프로그램에서 진행 중인 작업이 끝난 뒤 앱을 종료하고, 새 0.2.0 설치파일로 설치합니다. Mac에서는 Applications의 기존 앱을 새 앱으로 교체합니다. 자동 업데이트 기능은 없으므로 새 설치파일을 받아 설치해야 합니다.

연결 토큰은 운영체제의 보안 저장소에 보관됩니다. 업데이트 후 **계정 연결 / 시작**을 누르고 기존 연결 상태를 확인하세요. 연결이 만료되었거나 다시 승인을 요청하면 기존과 같은 ClassTalk 교사 계정으로 연결합니다.

0.2.0은 더 큰 음성 인식 모델과 음성 구간별 처리를 사용합니다. 무음이 발화시간에 포함되는 오류를 줄이고, 판단이 어려운 짧은 발화의 화자는 **미상**으로 표시합니다. CPU와 메모리를 더 사용하며, 컴퓨터와 녹음에 따라 처리 시간이 녹음 길이보다 길 수 있습니다. 전사가 끝날 때까지 앱과 컴퓨터를 켜 두세요.

기존 전사본은 업데이트만으로 바뀌지 않습니다. 기존 녹음의 무음 포함 시간이나 화자 표시를 새 방식으로 처리하려면 0.2.0으로 다시 전사해야 합니다. AI 분석도 기존 저장 결과를 자동으로 다시 생성하지 않습니다. 새 전사 결과를 확인한 뒤 필요한 분석을 다시 실행하세요.

## 계정 및 데이터

교사 비밀번호와 Supabase 관리자 키를 프로그램에 입력하지 않습니다. 연결 토큰은 macOS 키체인 또는 Windows 자격 증명 관리자에 저장됩니다. 웹 다운로드 페이지의 기기 목록에서 연결을 해제할 수 있습니다.

녹음을 컴퓨터로 내려받아 음성을 인식하고 전사 결과를 ClassTalk에 저장합니다. 처리 종료 시 임시 음성 파일을 삭제하지만, 앱이 강제 종료되면 OS 임시폴더에 남을 수 있습니다. 처음 모델 다운로드와 ClassTalk 연결에는 인터넷이 필요합니다.

## 설치파일 확인

릴리스에 파일별 SHA-256 체크섬과 서명 상태를 제공합니다. 초기 빌드는 Apple Developer ID 공증 및 Windows 배포자 서명이 적용되지 않은 상태입니다. 학교·기관의 설치 정책에 맞게 사용해 주세요.

이 저장소에는 설치파일, 체크섬, 사용자 안내만 게시합니다. 앱의 타사 구성요소와 라이선스 고지는 설치파일에 포함됩니다.
