# ClassTalk 전사 프로그램

ClassTalk에서 녹음한 **내 수업**을 선생님 컴퓨터에서 전사하는 프로그램입니다. Python이나 FFmpeg를 따로 설치하지 않아도 됩니다.

## 다운로드

[ClassTalk 다운로드 페이지](https://classtalk-web-three.vercel.app/worker)에서 컴퓨터에 맞는 설치파일을 받을 수 있습니다. [최신 공개 릴리스](https://github.com/phdkim0244-droid/classtalk-worker-downloads/releases/latest)에도 설치파일과 체크섬을 제공합니다.

## 지원 환경

- Windows 10 이상, x64
- macOS 13 이상, Apple Silicon 또는 Intel (각각 다른 파일)

Mac 실행 검사는 macOS 15의 Apple Silicon·Intel 환경에서 수행했습니다. macOS 13·14에서는 별도 실행 검증을 하지 않았습니다.

## 사용 순서

1. 본인 컴퓨터에 맞는 설치파일을 받습니다.
2. Windows는 Setup.exe로 설치하고, Mac은 DMG 안의 앱을 Applications로 옮깁니다.
3. 프로그램의 **계정 연결 / 시작**을 누릅니다.
4. 열린 ClassTalk 브라우저에서 본인 교사 계정으로 로그인하고, 기기 이름과 연결 코드를 확인한 후 승인합니다.
5. 처음 시작하면 공개 Whisper large-v3 음성 인식 모델 약 3.1GB를 내려받습니다. 0.2.2의 GPU 모델은 기존 CPU 모델과 별도이므로 처음 한 번 추가 다운로드가 필요합니다. 모델 준비가 끝날 때까지 인터넷 연결과 앱을 유지합니다.
6. 웹 수업 화면에서 **전사 시작**을 누르고 이 프로그램을 켜 둡니다. 결과는 웹 전사본에서 확인합니다.

본인 계정이 만든 수업만 배정됩니다. 학생 녹음 기기에는 설치할 필요가 없습니다. 전사 후 AI 내용 분석은 기존 ClassTalk 웹 기능을 사용합니다.

## 0.2.3으로 업데이트

기존 전사 프로그램에서 진행 중인 작업이 끝난 뒤 앱을 종료하고, 새 0.2.3 설치파일로 설치합니다. Mac에서는 Applications의 기존 앱을 새 앱으로 교체합니다. 자동 업데이트 기능은 없으므로 새 설치파일을 받아 설치해야 합니다.

연결 토큰은 운영체제의 보안 저장소에 보관됩니다. 업데이트 후 **계정 연결 / 시작**을 누르고 기존 연결 상태를 확인하세요. 연결이 만료되었거나 다시 승인을 요청하면 기존과 같은 ClassTalk 교사 계정으로 연결합니다.

0.2.3에서는 일반 수업의 **교사 채널에 올린 혼합 음성도 여러 화자로 구분**합니다. 전사 전에 실제로 말한 인원(교사 포함)을 입력할 수 있으며, 완료 후에는 웹의 **교사·학생 역할 확인**에서 앞·중간·뒤 음성 예시를 듣고 역할을 지정합니다. 확인하지 않은 화자는 자동으로 학생으로 바뀌지 않습니다.

짧은 응답은 두 로컬 음성 모델이 같은 화자를 가리키고 점수 차이가 충분할 때만 연결합니다. 추가 CAM++ 모델 약 28MB는 설치파일에 포함되며, 이 단계의 진행률과 예상 남은 시간을 표시합니다. 확실하지 않은 응답과 겹친 목소리는 여전히 **미상**으로 남을 수 있습니다. 역할이 섞인 항목은 미확인으로 유지하고 원음을 확인하세요.

웹에서도 1,000개를 넘는 전사를 전체 조회·CSV 내보내기·시간 집계·AI 입력에 포함합니다. 긴 입력은 구간별 근거 검토 후 합칩니다. 기존 전사와 AI 결과는 자동으로 바뀌지 않으므로, 기존 결과를 CSV로 보관한 다음 **새 세션**에서 다시 전사하고 역할 확인 후 AI 분석을 실행하세요.

### 기존 GPU 가속과 진행률

0.2.2부터 적용된 가속은 0.2.3에서도 유지됩니다. 아래 벤치마크는 0.2.2에서 측정한 기록이며 새 화자 확인 단계의 추가 시간은 포함하지 않습니다.

0.2.2는 large-v3를 유지하면서 **macOS 15 이상의 Apple Silicon에서 GPU 가속**을 사용합니다. Windows·Intel Mac·이전 macOS는 CPU에서 음성을 묶어 처리합니다. **CPU 호환**을 선택하면 기존 발화별 처리 방식으로 돌아갑니다. GPU 준비가 실패하면 중지한 상태에서 CPU 호환으로 다시 시작할 수 있습니다.

같은 2분 52초 합성 대화의 전사·화자 구분은 Apple M5 Mac에서 이전 CPU 기록 약 6분 17초에서 GPU 약 58초로 줄었습니다. 같은 대화를 반복한 40분 파일은 **11분 53초**였습니다. 모델 준비·업로드·웹 AI 분석은 제외한 시간이며, 실제 수업을 분석까지 10분 안에 끝내는 속도를 보장하지 않습니다. 과거 CPU 기록과 동시 부하를 통제한 비교도 아닙니다. 자세한 조건은 [벤치마크 기록](pipeline/desktop/BENCHMARK.md)을 참고하세요.

같은 교사·학생 합성 대화와 별도 2mL/1mL·8mL/9mL 테스트를 확인했습니다. 일반 한국어 단어 오인식은 남으며, 합성 음성 검사가 실제 수업의 정확도를 보장하지 않습니다. GPU와 CPU의 전사 문구도 다를 수 있습니다. 중요한 숫자와 문장은 원음을 확인하세요. 기존 음성 구간 시각, 짧은 발화의 **미상** 화자 처리, 계정별 수업 권한은 유지합니다.

워커 화면은 밝은 배경·진한 글씨로 바꾸고, 현재 파일·처리 단계·진행률·경과 시간·**현재 단계의 예상 남은 시간**을 표시합니다. 진행률은 실제 처리된 음성 구간을 기준으로 갱신됩니다. 최소 3개 구간과 10초의 기록이 쌓인 뒤 남은 시간을 추정하며, 다음 단계·다음 파일·웹 AI 분석은 포함하지 않습니다. 초기에는 계산 중, 추정이 낡으면 갱신 대기로 표시합니다. 한 단계의 100%가 전체 수업 완료를 뜻하지는 않습니다.

기존 전사본과 AI 분석은 업데이트만으로 바뀌지 않습니다. 기존 녹음을 새 처리 방식으로 확인하려면 다시 전사한 후 필요한 분석을 실행하세요. 전사가 끝날 때까지 앱과 컴퓨터를 켜 두세요.

## 계정 및 데이터

교사 비밀번호와 Supabase 관리자 키를 프로그램에 입력하지 않습니다. 연결 토큰은 macOS 키체인 또는 Windows 자격 증명 관리자에 저장됩니다. 웹 다운로드 페이지의 기기 목록에서 연결을 해제할 수 있습니다.

녹음을 컴퓨터로 내려받아 음성을 인식하고 전사 결과를 ClassTalk에 저장합니다. 처리 종료 시 임시 음성 파일을 삭제하지만, 앱이 강제 종료되면 OS 임시폴더에 남을 수 있습니다. 처음 모델 다운로드와 ClassTalk 연결에는 인터넷이 필요합니다.

## 설치파일 확인

릴리스에 파일별 SHA-256 체크섬과 서명 상태를 제공합니다. 이 버전은 Apple Developer ID 공증 및 Windows 배포자 서명이 적용되지 않은 상태입니다. 학교·기관의 설치 정책에 맞게 사용해 주세요.

이 저장소에는 설치파일, 체크섬, 사용자 안내와 설치형 워커의 소스·빌드 도구를 게시합니다. 웹앱 코드, 계정 정보와 실제 수업 음성은 포함하지 않습니다. 테스트 음성은 합성 회귀 검사 자료입니다. 앱의 타사 구성요소와 라이선스 고지는 설치파일에 포함됩니다.

## 워커 빌드

`pipeline/desktop`과 `pipeline/packaging`에 설치형 워커 및 패키징 코드를 제공합니다. `WORKER_SOURCE.json`에서 원본 버전과 파일별 SHA-256을 확인할 수 있습니다. 사용자는 직접 빌드할 필요 없이 위 다운로드 페이지에서 공개된 설치파일을 받으면 됩니다.

저장소 소유자는 Actions의 **Build ClassTalk desktop worker**를 수동 실행하여 Windows x64, Mac Apple Silicon, Mac Intel 설치파일을 빌드하고 실제 실행 검사를 수행할 수 있습니다. 표준 GitHub 호스팅 실행기를 사용하는 공개 저장소 빌드입니다. 빌드 결과는 검증 후 별도로 릴리스에 게시하며, 소스가 갱신됐다고 다운로드 버전이 즉시 바뀌지는 않습니다.
